VOICE COMPANION - UPDATES

1. Update the app
Companion checks for updates when it starts, unless this choice is turned off in Options.
Say "Check for updates" to check at any time. If an update is offered, say "Yes" to install or "No" to keep working.
An update offered later waits for a suitable pause in your work.

2. What happens after Yes
1. Companion saves the current work.
2. It downloads the full installer.
3. It checks that the download matches the published file.
4. It closes and runs setup.
5. It opens again when setup finishes.
Say "Update status" to hear progress. Say "Cancel update" while the file is downloading to stop.
Status works while download speech is playing. After the download is checked, the app prepares setup. A checked update cannot be canceled once setup is being prepared.
During setup, a separate update window listens for "Status" or "Update status". Press its Status button or Enter for keyboard access.
Companion opens again and says its new version, that the update worked, and whether the microphone is on. Say "Wake up" or use the keyboard when ready. If the microphone is off, it opens on the main menu. It tries the microphone again if Windows is still releasing it.
A Windows security prompt may need help. A computer restart is not forced. Companion tells you if one is needed.
The update keeps your account data and personal files. It also refreshes the user guides.

3. If an update fails
Keep using the current version if it opens. Note the exact error message.
Check internet access and free disk space. Try "Check for updates" again later.
Ask a support person for help if setup is blocked or the desktop icon opens an older version.
The app keeps update records for support. You do not need to edit them.

4. Find the new guide and notes
Say "Open user guides". Open the guide or release notes in the format you prefer.
Close and reopen any guide that was already open before the update.
Release notes explain the changes from the earlier version. Read them before trying a changed task.

5. Publish an update
This part is for the person who makes and shares the app. People who only use it do not need a GitHub account.
Updates are built on GitHub, in willwalsh1997-byte/voice-companion-updates.
They are shared from updates.voicecompanionapp.com.
The newest installer is always at updates.voicecompanionapp.com/VoiceCompanion-Setup.exe.
A change to the app's files on the main branch starts the build. It checks the app and the installer first. Only a build that passes is shared.
A failed build shares nothing. Each update needs a new version number.
Build details are in GITHUB AUTOMATED BUILDS.txt.

6. Test build on your own computer
BUILD INSTALLER - Double click.cmd makes an installer for testing on this computer. It is never shared as an update.
Do not put passwords or sign-in codes in the source folder.

7. Check on a real computer
Check update Yes and No, a lost internet connection, and canceling a download.
Check that saved work, settings, accounts, and the guide copies remain right after an update.
Check that the app closes for setup and opens again afterward.
Record what passed, what failed, and what you did not test. Use TRAINER TEST CHECKLIST.txt.
